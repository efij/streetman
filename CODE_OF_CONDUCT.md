# Code of Conduct

## Short version

Be respectful. Technical disagreement is encouraged — personal attacks are not.

## The rules

1. **Be kind.** Attack ideas, not people.
2. **Assume good faith.** Ask before accusing.
3. **Criticize specifically.** "This accuracy rubric misses X" beats "this is bad."
4. **Respect the bench.** If you disagree with a measurement, produce a counter-measurement, not a complaint.
5. **No harassment.** Zero tolerance. Includes sexist/racist/homophobic/transphobic language, doxxing, threats, unwanted sexual attention.
6. **No spam.** Promotional content, off-topic posts, recruitment — all out.

## Enforcement

Violations: email `conduct@streetman.dev`.

First offense: warning.
Second offense: temporary ban.
Severe or repeated: permanent ban from repo, discussions, Discord.

Maintainers enforce this in all project spaces: GitHub (issues, PRs, discussions), Discord, community calls.

## Scope

Applies in all project spaces + when representing the project publicly (conference talks, blog posts, social media using streetman branding).

## Based on

[Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) — adapted for technical specificity.
